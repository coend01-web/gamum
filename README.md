# 가뭄 사용성 간소화 검토본

현재 작업은 **로컬 `ux-simplify-v1` 브랜치**에 있습니다. GitHub로 push하거나 공개 홈페이지에 배포하지 않았습니다.

최신 간소화 작업 및 검증 내용은 `docs/UX-SIMPLIFY.md`에 있습니다. 이전 `design-v1`은 그대로 보존했습니다.

## 실행

`index.html`을 브라우저로 열면 사용할 수 있습니다. 별도 설치·빌드가 없는 정적 웹사이트입니다.

로컬 서버가 필요한 경우 이 폴더에서:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/`를 엽니다. 종료는 터미널에서 Ctrl+C입니다.

## 구조

- `index.html`: 공통 헤더·탐색 메뉴·본문·푸터
- `assets/css/legacy.css`: 기존 컴포넌트 구조와 보존된 스타일
- `assets/css/design.css`: v1.0 디자인 토큰·공통 컴포넌트·반응형 규칙
- `assets/js/data.js`: 기존 시연 데이터, 원본 그대로 유지
- `assets/js/app.js`: 기존 화면과 동작, 카드·목록·묵상 공통 렌더링
- `docs/ASSETS.md`: 이미지·폰트 출처와 이미지 생성 프롬프트
- `tests/regression.mjs`: 원본과 추천 계산 비교 및 주요 기능 검사

기존 네 가지 탐색, 10문항, 결과 저장·이미지 다운로드·공유, 1분 머뭄, 서랍, 수도회 등록, 모집 상태·예약 연동·QR 후기 시연을 유지합니다.

## 별도로 검증한 상호작용 변경

- 1분 머뭄: 위로 → 말씀 → 질문 → 기도, 한 번에 하나씩 읽기
- 주제 목록: 가까운 날짜·낮은 참가비·높은 참가비 정렬
- 수도회 등록 시 입력한 참가 대상을 상세에도 유지
- 저장된 결과의 마지막 버튼이 실제 탐색 화면으로 연결
- 키보드 초점 유지, 본문 바로가기, 선택된 날짜·지역·메뉴 안내
- 정적 시연에서는 존재하지 않는 API를 호출하지 않음. 기존 서버 연동 코드는 보존했으며 실제 서버 환경에서만 `<html data-status-api="enabled">`로 켭니다.

## 보존된 원본

- 원본 커밋: `c9185d0` (v0.6)
- 복구 태그: `baseline-v0.6-2026-11-05`
- 원본 `main` 브랜치는 변경하지 않았습니다.

원본을 별도로 확인하려면 변경사항을 먼저 커밋하거나 보관한 다음 `git switch main`을 사용합니다. 현재 디자인으로 돌아올 때는 `git switch ux-simplify-v1`을 사용합니다.

## 검사

Node.js가 있는 환경에서:

```sh
node tests/regression.mjs
```

원본 태그가 있는 Git checkout에서 실행합니다. 원본 카탈로그 동일성, 24가지 답변 조합별 추천 동일성, 모집 상태, 13개 경로, 1분 머뭄 단계, 정렬, 참가 대상 유지 등을 검사합니다.

브라우저 검증은 360·390·768·1440px에서 수행했습니다. 실물 iOS/Android 기기에서의 검증은 포함하지 않습니다. 외부 공유 메시지를 실제로 전송하지 않았습니다.

## 시연 범위

모든 기관·일정은 가상 데이터이며 신청·결제는 연결되지 않습니다. 서랍만 현재 브라우저에 저장됩니다. 등록 시연 자료는 페이지를 새로고침하면 사라집니다. 실제 시설 사진·후기·실제 예약 연동·로그인은 기존과 같이 정식 기능이 아닙니다.
