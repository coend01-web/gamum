# Codex 작업 지시서 — 가뭄 일상형 10문10답 v2.0

저장소: https://github.com/coend01-web/gamum
기획 문서: https://github.com/coend01-web/gamum/blob/quiz-research-v1/docs/quiz-everyday-v2-implementation.md
기존 분류 연구: https://github.com/coend01-web/gamum/blob/quiz-research-v1/docs/retreat-taxonomy-and-quiz-v1.md

## 작업 목표
기획 문서를 끝까지 읽고, 기존 10문항을 '일상의 재미있는 질문'으로 교체하고 실제 가톨릭 머뭄•피정 프로그램과 다차원 특성·참가 조건을 매칭하도록 개발해 주세요.

## 구현 필수 요구
1. main에서 새로운 작업 브랜치 quiz-everyday-v2-impl을 만들어 진행합니다. 기존 기능은 보존합니다. 공개 페이지 배포/병합은 제 승인 전까지 하지 마세요.
2. 기획 문서 3장의 Q1~Q10 질문·답변 ID·라벨을 그대로 적용합니다. 질문 및 답변은 코드와 분리하여 쉽게 수정되도록 합니다.
3. 각 응답의 feature 점수·예외 규칙, 기간/동행 선호, 피정 프로그램의 목적·영성·운영 방식·참가 자격을 구분합니다.
4. 생활 질문만으로 특정 영성 선호를 단정하지 마세요. '책 읽기'는 성경 피정의 약한 간접 단서일 뿐입니다.
5. 실제 프로그램의 대상·연령·신청 조건·회차·모집 상태를 우선 검토하고, 그 뒤 취향 점수로 최대 3개를 추천하세요. 0~2개면 있는 만큼만 보여줍니다.
6. 결과는 '짧은 결과 제목 → 추천 피정 최대 3개 → 조건 조정 → 위로·성경·성인·묵상·기도 → 저장/공유' 순서로 유지합니다.
7. 네 가지 피정 찾기, 1분 머뭄, 서랍, 수도회 관리, 일정, QR 후기, 모바일 스크롤 수정 등 기존 기능을 삭제하거나 망가뜨리지 마세요.
8. '오늘, 1분 머뭄'은 처음부터 펼쳐 보이고 + 토글을 누르도록 요구하지 마세요.
9. 가상 데이터임을 분명히 표시하고 실제 예약·신청 가능으로 오인시키지 마세요. 수엘 캐릭터를 추가하지 마세요. CAMUM/GAMUM 영어 로고는 아직 미확정이므로 임의 변경 금지입니다.
10. 모바일/PC에서 작동 검증과 기획 문서 8장의 테스트 사례를 구현하고 자동 테스트 로그와 전후 화면을 보여주세요.
