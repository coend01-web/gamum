## 변경 범위

기존 홈페이지 구조·레이아웃·타이포그래피·탐색 위치를 유지하고 평면 SVG 중심 비주얼을 20개의 사진적 질감과 공간 깊이를 갖춘 AI 제작 이미지로 교체했습니다. 실제 장소를 촬영한 사진이 아닙니다. 화면 캡션, 대체 텍스트, 이용 안내, 하단에서 가상의 공간임을 명시합니다.

- 오래된 SVG 40개는 삭제하지 않았습니다. 이전 디자인 브랜치 및 이력도 보존합니다.
- 80단계 묵상 원고, 네 가지 탐색, 질문과 숨은 태그, 추천 엔진, 저장·등록·후기 코드는 보존합니다.
- public main/v0.2, v0.21 운영 기능 및 Supabase 데이터/권한 변경 없음.
- 사이트 구조는 같으며, 이미지 표시 중심과 이미지의 실제 촬영물이 아니라는 안내만 바꿨습니다.

## 자산과 재현

- 생성: 내장 이미지 생성 도구. 외부 시설 사진/검색 이미지 사용 없음.
- 최종 프롬프트 20개: `docs/CAMUM_ART_V2_PROMPTS.json`.
- 이미지 설명·PC/모바일 표시 중심: `design/art-v2/manifest.json`.
- 사이트용: `design/art-v2/`에 JPEG 60개. 1440px 대표 이미지, 720px 모바일, 400px 갤러리.
- 60개 합계 8,959,602 bytes, 한 이미지 최대 462,519 bytes. 갤러리는 400px 자산을 지연 로딩하고 메인에는 해당 테마 하나만 우선 로딩합니다.
- 원본 PNG 20개는 작업 폴더의 `outputs/camum-art-v2/originals/`에 별도 보존합니다. 이 큰 원본은 사이트 배포에 포함하지 않습니다.
- 인코딩: macOS `sips`로 크기와 JPEG 압축만 조절합니다. 생성 후 색을 덧칠하거나 질감을 기계적으로 합성하지 않았습니다. 재생성은 `scripts/encode-art-v2.mjs` 참조.

## 검증

- `npm test`: 기존 전체 자동 검사 통과.
- `node tests/design-spaces.mjs`: 기존 20개/80단계/방문 순환/대비/저장 검사 통과.
- `node tests/art-v2.mjs`: 20개 자산 연결, 60개 고유 파일, 용량 제한, 원고·질문·추천·저장/탐색 이벤트 처리 코드 보존 및 기존 레이아웃 CSS 보존 검사 통과.
- 실제 브라우저 20개 테마: 390px에서 모바일 이미지 정상 표시 20/20, 가로 넘침 없음. 네 가지 탐색 하단 위치 786.49px로 모두 동일.
- 360·390·768·1440px: 적절한 이미지 선택, 가로 넘침 없음.
- 모바일 10문항 전부 클릭: 질문 상단 189.8px 고정, 스크롤 0, 선택지 하단 최대 670.8px. 결과 3개 표시.
- 1분 머뭄 진행 후 새로고침: 단계 유지. 브라우저 콘솔 오류 없음.
- PC 갤러리 20개 전체 표시, 모바일 대표 구도(빛·쉼·씨앗 등) 실제 스크린샷 확인.
