## 원인과 수정

- 공개 정적 카탈로그의 승인·공개 실제 회차는 0건이다. 이전 검색은 이 빈 카탈로그를 기본으로 검색하고, 기존 예시는 자료 구분 메뉴를 선택해야 보였다. 매핑이나 결과 렌더링의 누락은 발견되지 않았다. 이번 작업에서 Supabase 데이터는 조회·변경하지 않았다.
- 공개 카탈로그를 정상적으로 읽었고 전국 전체 자료가 비어 있을 때만 기존 예시를 자동 표시한다. 실제 자료가 하나라도 있으면 실제 자료만 검색하며, 검색 결과가 0건이라고 예시로 바꾸지 않는다. 통신 실패도 빈 자료로 취급하지 않는다.
- 자료 선택 메뉴를 제거했다. 예시는 결과 영역의 신청 불가 안내 및 각 행의 `시연 · 신청 불가` 표시로 구별한다. 실제 신청 버튼은 여전히 실제 자료에서만 허용한다.
- v0.2의 명시적인 ‘선택한 모든 태그’ AND 규칙을 보존했다. 같은 그룹의 OR로 바꾸지 않았으며 화면에 선택 규칙을 안내한다. 24개 고정 태그·원본 태그·추천 계산·자격 검사에는 변경이 없다.
- 각 태그가 단독으로 존재하지만 교집합이 없는 경우와, 날짜·지역·자격 조건에서 해당 태그가 없는 경우를 구분하여 안내한다.
- 네 탐색의 목록은 제목, 장소·지역, 작은 시연 표시의 공통 클릭 행으로 정리했다. 일정·비용·대상·설명·추천 이유·저장·신청 안내는 상세 화면에 유지한다. 상세 후 브라우저 뒤로 가기 및 목록 링크로 조건·스크롤을 복원한다.
- 저장한 예시는 실제 자료가 들어와도 출처를 유지한 상세 경로로 다시 열 수 있다. 개인 서랍을 초기화하지 않는다.
- 흐림의 원인은 이미지 자체 opacity/blur가 아니라 넓은 아이보리 그라데이션이었다. 모바일의 중앙·오른쪽 오버레이와 하단 페이드를 줄이고, 20개 테마에 강도·종료 위치를 따로 지정했다. 글 주변 대비를 위해 문장 폭도 조정했다. 원본 및 웹 이미지 파일은 변경하지 않았다.

## 실제 자료를 바꾸지 않고 검증한 태그

프로그램 수와 회차 수는 다르다. 아래는 서로 다른 프로그램 수다.

| 선택 | 프로그램 수 | 확인 |
|---|---:|---|
| 관계 | 2 | 가족·화해 |
| 관계 + 나눔 | 1 | 가족 |
| 관계 + 나눔 + 성경 | 0 | 세 조건을 모두 가진 기존 예시 없음 |
| 쉼 + 침묵 | 2 | 침묵·제주 |
| 말씀 + 성경 | 4 | 청년·말씀·청소년·대림 |

성경 단독은 브라우저에서 5회차, 쉼+침묵은 3회차, 침묵 해제 후 쉼은 5회차, 전체 초기화 후 14회차를 확인했다. 시연 일정도 시간이 지나면 검색에서 제외된다.
