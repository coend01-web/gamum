제작일: 2026-11-12. 디자인 검토 전용 브랜치의 독창적인 벡터 그래픽이다. 외부 사진이나 제3자 그래픽을 포함하지 않으며 실제 수도회·피정 시설을 촬영하거나 재현한 자료가 아니다. 롱샹 건축의 형태를 복제하지 않고 빛·벽·그림자·여백의 관계를 참고했다.

## 렌더 검증 결과

40개 파일을 macOS SVG 렌더러로 PNG 변환하고 PC 20개 / 모바일 20개 비교 시트를 확인했다. 누락·XML 오류·깨진 외부 참조는 없었다. 독립된 문·아치·회랑·창·계단·곡면·가구·수로 구성으로 20개 공간의 차이를 확인했다. 모바일 파일은 이후 실제 350×174px 히어로에 맞춰 약 2:1 구도로 재검토했다. 첫 화면에서 네 가지 길이 보이도록 이미지 높이를 낮추면서 씨앗·의자·잔·계단 등 핵심 사물은 유지한다.
