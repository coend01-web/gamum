## 1. 목적과 원칙

가뭄은 신자들이 흩어진 피정을 찾아 연락처와 신청 경로까지 알기 어렵고, 수도회는 좋은 피정을 기획하고도 널리 홍보하지 못하는 단절을 해결한다. 10문항은 **심리테스트처럼 재미있게 시작해서 실제 참가할 수 있는 머뭄•피정에 도달**하는 입구다.

- 질문은 생활 속 장면을 다루고, 종교적 용어를 굳이 앞세우지 않는다.
- 답변은 **하나의 성격 유형에 가두지 않는다**. 일상 선호는 종교적 피정 형태와 1:1로 같지 않다. 책 읽기=성경 읽기, 자연 산책=프란치스코 영성, 음악=성령쇄신이라는 단정 금지.
- 10문항은 마음의 필요·콘텐츠·진행 방식·동행·시간을 파악한다. 연령·예산·장소·정확한 날짜·선행 경험·특정 영성은 결과 화면의 선택적 조건 조절로 보완한다.
- 실제 수도회가 등록한 프로그램의 주제·전통·대상·회차·공식 신청 정보를 활용한다. 알고리즘이 존재하지 않는 프로그램·회차·잔여석을 만들지 않는다.
- 결과 순서: 짧은 유형 소개 → **실제 피정 추천 최대 3개** → 조건 다시 고르기 → 위로·성경·성인·묵상·기도 → 저장·공유.
- 시연 데이터는 '가상'을 명확히 표시. 공개 홈페이지 main 브랜치는 사용자 승인 전 변경하지 않는다. 수엘 캐릭터 제외. CAMUM/GAMUM 표기는 아직 미확정.

## 2. 피정 분류 체계 (프로그램에 복수 태그)

1. **목적**: 쉼, 신앙의 재시작, 성경·말씀, 식별, 성소, 관계, 부부·가족, 화해·용서, 영적 위로, 신앙교육, 공동체, 감사, 생태영성, 봉사·선교, 전례 시기.
2. **영성·전통**: 이냐시오 영신수련, 렉시오 디비나, 관상/향심기도, 예수마음기도, 성체조배, 성령쇄신·찬양, 성모신심, 베네딕도, 가르멜, 프란치스코, 수도생활 체험, 공식 피정으로 분류된 순례형 프로그램.
3. **운영 방식**: 대침묵, 부분 침묵, 개인 자유피정, 지도형, 일대일 영적 면담, 강의, 소그룹 나눔, 공동기도, 찬양, 걷기, 예술, 봉사, 당일, 숙박, 통원·일상 피정, 온라인, 본당 단체 위탁.
4. **대상·자격**: 연령, 개인/단체, 부부·가족/부모 자녀 등 동행 조건, 성소 관심자, 청소년·청년·중년·시니어, 수도자·성직자 전용, 성별·신앙 단계·선행 피정 경험 등 *주최 측이 명시한 조건*.
5. **실제 회차**: 시작·끝·접수 시작·마감 시각, 참가비, 장소, 정원, 모집 상태(확인 시각 포함), 공식 연락처·신청 URL.

**새로운 피정 종류를 발견해도 질문 10개를 고정한 채 태그를 확장**할 수 있어야 한다.

## 3. 사용자에게 보여줄 최종 10문항과 답변 매핑

대괄호의 영문 키·점수는 **화면에 표시하지 않는** 내부 태그 초안이다. 1~3은 선호의 상대 가중치다. '건너뛰기' 가능.

### Q1. 토요일 약속이 갑자기 취소됐습니다. 첫 반응은?
- A. 야호! 드디어 혼자만의 시간. [solitude:3, rest:2]
- B. 그럼 어디라도 나가볼까? [experience:3, movement:2]
- C. 오랜만에 누군가에게 연락해야지. [connection:3, sharing:2]
- D. 미뤄 둔 책이나 영화를 봐야겠다. [reflective:3, learning:1]

### Q2. 내 인생에 버튼 하나를 추가할 수 있다면?
- A. ⏸ 일시정지 — 아무것도 안 하고 싶다. [rest:3, quiet:2]
- B. ↩ 되감기 — 그때 그 말을 바꾸고 싶다. [reconciliation:3, relationship:2]
- C. 🧭 길찾기 — 어디로 가야 할지 모르겠다. [discernment:3]
- D. ↻ 새로고침 — 뭔가 새롭게 시작하고 싶다. [renewal:3]
- E. 🔇 음소거 — 잠시 세상 소리를 끄고 싶다. [quiet:3, solitude:2]

### Q3. 여행에서 가장 오래 기억에 남는 것은?
- A. 창밖을 보며 아무 말도 하지 않았던 시간. [quiet:2, solitude:2]
- B. 우연히 만난 사람과의 대화. [connection:3, sharing:2]
- C. 처음 알게 된 흥미로운 이야기. [learning:3, reflective:2]
- D. 예상하지 못한 특별한 경험. [experience:3, movement:2]

### Q4. 영화를 보고 나서 가장 오래 남는 장면은?
- A. 대사 없이 조용히 흘러가는 장면. [quiet:3, contemplative:2]
- B. 멀어졌던 사람들이 다시 만나는 장면. [reconciliation:3, relationship:2]
- C. 주인공이 자신의 길을 결정하는 장면. [discernment:3, renewal:1]
- D. 서로 다른 사람들이 하나가 되는 장면. [community:3, sharing:2]
- E. 평범한 일상을 다르게 보게 하는 장면. [reflective:3, renewal:1]

### Q5. 마음이 복잡할 때 가장 도움이 되는 것은?
- A. 아무도 나를 건드리지 않는 시간. [solitude:3, quiet:2]
- B. 내 이야기를 끝까지 들어 주는 사람. [one-on-one:3, connection:2]
- C. 생각을 정리해 주는 책이나 좋은 말. [reflective:3, learning:2]
- D. 몸을 움직이거나 새로운 일을 해 보는 것. [movement:3, experience:2]
- E. 음악을 듣거나 함께 노래하는 시간. [music:3, community:1]

### Q6. 낯선 곳에 도착하면 무엇을 먼저 할까요?
- A. 조용한 곳에 앉아 분위기를 느낀다. [quiet:2, solitude:2]
- B. 사람들과 인사를 나눈다. [connection:2, sharing:2]
- C. 안내문과 일정을 꼼꼼히 읽는다. [guided:2, learning:2]
- D. 주변을 돌아다니며 직접 살펴본다. [experience:3, movement:2]
- E. 누군가 친절히 안내해 주면 좋겠다. [guided:3, beginner-friendly:2]

### Q7. 하루 동안 휴대전화 알림이 모두 꺼진다면?
- A. 완벽해! 아무도 연락하지 않았으면. [quiet:3, solitude:2]
- B. 가끔은 좋지만 대화도 하고 싶다. [partial-silence:3, sharing:1]
- C. 중요한 연락은 놓치고 싶지 않다. [flexible:3]
- D. 차라리 재밌는 활동을 하고 싶다. [experience:2, movement:2]
- E. 누구와 함께 있느냐에 따라 달라질 듯. [company-sensitive:2]

### Q8. 나 자신에게 선물할 수 있다면?
- A. 아무 계획 없는 휴식 시간. [rest:3, self-directed:2]
- B. 마음에 오래 남을 책 한 권. [reflective:3, learning:2]
- C. 진지한 대화를 나누는 저녁. [connection:2, one-on-one:2]
- D. 새로운 세계를 경험할 기회. [experience:3, renewal:1]
- E. 누군가에게 도움이 될 기회. [service:3, community:1]

### Q9. 나에게 선물할 수 있는 시간은 어느 정도인가요?
- A. 하루 정도. [duration:day]
- B. 주말, 1박 2일. [duration:one-night]

### Q10. 이번에는 누구와 떠나고 싶나요?
- A. 혼자. [company:solo]
- B. 친구나 지인과. [company:friends]

## 4. 추천 연결 규칙

### 일상 선호 → 피정 태그 (약한 추론과 직접 선호 구분)
- rest → 쉼·개인 자유피정 등에 높은 가산.
- quiet, solitude, contemplative → 침묵·관상·개인 피정에 가산. **대침묵·심화 과정은 선행 경험·규칙 확인.**
- reflective, learning → 영성독서·성경 묵상·강의·렉시오 디비나에 *약한* 가산. 책을 좋아한다고 성경 피정으로 확정 금지.
- connection, sharing, community → 공동체·나눔·관계 피정.
- reconciliation, relationship → 화해·부부/가족 등 관계 목적 가산. 실제 참가자 자격은 따로 확인.
- discernment → 영신수련·식별형 피정 후보에 가산. 수도 성소 전용은 별도 자격 심사.
- renewal → 신앙 재시작·입문·전례 피정 가산.
- movement, experience → 걷기·체험·봉사·생태 피정에 가산. 자연 선호로 단정 금지.
- one-on-one, guided → 영적 동반·안내형·초심자 친화 프로그램 가산.
- music → 찬양·음악이 **실제로 포함된** 피정 가산. 성령 피정을 자동 확정하지 않음.
- partial-silence → 부분 침묵에 가산, 장기 대침묵은 약한 감점.
- service → 봉사·실천형 피정 가산.
- flexible → 당일·통원·온라인 프로그램 적합성 가산.

### 필수 참가 조건은 점수와 분리
- 출발 모집 후보: 공고가 확인된 수도회 프로그램의 실제 미래 회차. 단, 현재 가상 데이터는 명확히 '시연용'.
- **하드 필터**: 실제 연령 제한, 성별 제한(주최가 명시한 경우), 특정 대상/혼인·가족·수도자·성소자·선행 과정·그룹 요건, 사용자 명시 필수 날짜·숙박·지역·예산. 정보 부족이면 '참가 대상 확인 필요', 임의로 통과시키거나 예약 가능으로 단정 금지.
- **소프트 선호**: Q1~Q8 태그, Q9~Q10 기본 시간·동행 성향. 사용자가 '이 기간만 가능' 또는 '숙박 불가' 등을 지정하면 명확히 필수조건으로 적용.
- 점수 예시: 직접 태그 일치 3, 관련 태그 1, 약한 추론 0.5에 각 선택지 가중치 반영. 한 질문이 독점하지 않도록 축별 정규화. 특정 수도회나 인기순으로 편향되지 않도록 다양성 보정.
- 추천 사유는 실제 피정 공고에 있는 특징과 선택 답변의 교집합으로만 작성.
- 추천이 0~2개면 해당 개수만 표시하고 '조건 넓혀 다시 찾기' 제공. **없는 추천 3개 억지로 채우지 않음.**
- 실시간 마감·잔여석 정보가 검증되지 않으면 '주최 측 확인 필요' 표기와 공식 연락/신청 경로 안내.

### 추가 조건 선택(10문항 뒤, 선택 사항)
'추천을 조금 더 정확하게' 아래에 간단한 조절 UI 제공:
- 지역, 실제 날짜, 예산, 연령/참가 대상, 동행 인원, 숙박·통원/온라인, 피정 선행 경험.
- 관심 영성: **말씀·성경 / 침묵·관상 / 영신수련·식별 / 성체조배 / 성모신심 / 찬양·성령 / 수도생활 체험 / 가족·관계 / 생태영성·봉사 / 잘 모르겠어요**.
- 이 선택은 10문항을 다시 하지 않아도 결과를 재정렬해야 함.
- 일반 생활 질문만으로 구체적인 영성 전통을 확정하지 않기 위한 장치임.

## 5. 결과 및 UX 화면

1. '당신에게 어울리는 머뭄' 유형 제목과 간단한 한 줄 위로. *유형은 내 마음을 돌아보는 문구이지 의학적·심리적 판정이 아님*.
2. **피정 추천 카드 최대 3개**: 수도회 이름, 프로그램명, 기간·일자, 장소, 참가비·대상, 검증된 모집 상태, 공식 연락처·신청 링크, 추천 이유.
3. '조건 바꾸기' 영역: 기본은 간결한 필터, 필요한 사람만 세부 조건을 조절.
4. 그 아래 **짧은 피정**: 위로의 말 → 새번역 성경 장절·공식 링크 → 영적 길동무 성인 → 묵상 질문 → 짧은 기도. 인용·성인 사실 검증 필수.
5. 결과 저장·공유와 다시 검사하기.

### 접근성과 기존 기능 보존
- 답변을 클릭할 때 페이지가 위로 튀지 않고 **질문 위치 유지**. 1/10 진행률·이전·건너뛰기·마지막 '결과 보기'.
- 어르신에게도 잘 보이는 글씨와 버튼(터치 영역), 탭·키보드·스크린리더 접근성.
- 첫 화면은 **네 가지 입구가 동등하게** 명확. '오늘, 1분 머뭄'은 +버튼 없이 처음부터 펼침. 지나친 카드·메뉴 중복 금지.
- 기존 날짜/지역/주제 탐색, 피정 상세, 수도회 등록·회차·QR·서랍·1분 머뭄 시연 기능을 유지.
- 한글 브랜드는 가뭄 · 가톨릭 머뭄; 영문 CAMUM/GAMUM 선택은 아직 보류. 수엘 캐릭터 사용 금지.

## 6. 반드시 자동 테스트할 사례

1. '책'을 선택해도 무조건 성경 피정으로만 나오지 않는가?
2. '되감기' + 영화 '화해' → 실제 화해·관계 피정이 있다면 순위가 올라가는가?
3. '길찾기' + 영화 '선택' → 식별 피정 후보 가산, 성소자 전용 무조건 추천 방지.
4. 음악 + 함께 활동 → 찬양 포함 프로그램 우선, 없는 찬양을 만들어내지 않는가?
5. 알림 유지 희망 + 나눔 선호 → 장기 대침묵 프로그램이 과도하게 추천되지 않는가?
6. 당일만 가능(필수조건) → 숙박 필수 프로그램 제외되는가?
7. 숙박 불가 → 온라인·통원·당일 이외 프로그램 제외되는가?
8. 배우자와 동행 → 부부 프로그램뿐 아니라 일반 피정의 동반 허용 여부도 확인하는가?
9. 가족+미성년 자녀 → 성인 전용 프로그램 제외되는가?
10. 처음 피정 → 선행 수련 필수인 장기 프로그램을 준비 없이 신청 가능으로 안내하지 않는가?
11. 이미 모집 마감/상태 미확인 → 접수 중이라고 허위 표기하지 않는가?
12. 후보 0·1·2개 → 가상 추천으로 채우지 않는가?
13. 모든 문항 건너뛰기 → 에러 없이 일반 피정 탐색으로 연결되는가?
14. 모바일 360·390·768px, PC 1280px에서 10문항 스크롤/결과/터치 확인.
15. 기존 4입구·1분 머뭄·서랍·수도회 등록·QR 등의 회귀 테스트 통과.
16. 새 피정 유형을 등록할 때 질문을 바꾸지 않고 태그로 연결 가능한가?

## 7. Codex 구현 순서

1. GitHub 저장소와 최신 main, 기존 분리된 JS/CSS 파일 구조를 확인.
2. 새 작업 브랜치(예: quiz-everyday-v2) 생성. main과 공개 GitHub Pages는 절대 직접 변경하지 않음.
3. Q1~Q10 질문을 별도 데이터 구조로 구현. 답변 tag/weight는 사용자에게 숨김.
4. 다차원 분류·적합성 필터·순위 계산을 UI 코드에서 분리하여 테스트 가능하게 구현.
5. 참가 자격·일정·연령 등 필수조건과 일상 취향의 소프트 점수를 구분.
6. 결과 하단 추가 조건 필터와 실제 피정 카드, 위로·성경·성인·묵상 보존.
7. 화면·동작 테스트, 변경 전/후 비교 및 테스트 보고서 제출.
8. 사용자 승인 전 main 병합/실제 공개 배포 금지.
