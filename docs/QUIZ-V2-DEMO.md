# v2 가상 피정 추천 체험

사용자 요청에 따라 `quiz-everyday-v2`에서 시연 참가 조건을 보완했습니다. main·GitHub Pages는 변경하지 않습니다.

## 가상 자료와 실제 자료 분리

원본 `assets/js/data.js`의 12개 프로그램·14개 회차는 그대로입니다. `assets/js/demo-catalog.js`가 복사본에만 시연 메타데이터를 추가합니다. 기존 ID와 `source:'가상 시연 데이터'`가 모두 일치하고, 실제 자료 표시 또는 기존 recommendation 정보가 없는 경우에만 적용합니다. 등록된 실제 프로그램·새 공고에는 적용하지 않습니다.

기본 시연 조건은 성별·신앙 단계·직분 제한 없음, 선행 과정 없음, 첫 피정 가능입니다. 연령 제한 없음 역시 확인을 생략한 뜻이 아니라 **이번 시연에서 명시적으로 정한 허구의 조건**입니다. 사용자 나이·혼인·신앙을 추측하거나 가상 참가자 정보를 대신 입력하지 않습니다. 실제 공고 검토 시 이 설정을 복사해선 안 됩니다.

원본의 일반 대상 표시는 보존하고, 화면에서는 아래 명시적 가상 참가 대상을 우선 표시합니다. 실제 기관의 자격을 새로 만들어 넣은 것이 아닙니다.

| 프로그램 | 가상 참가 조건·동행 | 가상 구성 |
|---|---|---|
| 잠시 멈추는 침묵의 시간 | 연령 제한 없음 / 혼자·친구·배우자 | 침묵·개인 휴식 |
| 청년과 함께 읽는 복음 | 만 19~39세 / 혼자·친구·배우자·단체 | 말씀·안내·나눔 |
| 숲에서 걷는 기도 | 연령·동행 제한 없음 | 걷기·체험·쉼 |
| 말씀과 함께하는 2박 3일 | 연령 제한 없음 / 혼자·친구·배우자·단체 | 성경 읽기·학습·묵상 |
| 바닷가에서 쉬어 가는 하루 | 연령·동행 제한 없음 | 당일 자유 휴식 |
| 제주의 고요한 머뭄 | 만 18세 이상 / 혼자 | 개인 침묵 |
| 처음 시작하는 관상기도 | 연령·동행 제한 없음 | 입문 안내·관상 |
| 삶의 선택을 위한 영신수련 | 연령 제한 없음 / 혼자·친구·배우자·단체 | 입문 식별, 성소 전용·심화 과정 아님 |
| 가족이 함께 머무는 주말 | 연령 제한 없음 / 가족·배우자 | 가족 대화·공동 활동, 자녀 허용 |
| 청소년을 위한 영성 캠프 | 만 13~18세 / 혼자·친구·단체 | 말씀·체험·공동체 |
| 용서와 화해의 길 | 연령·동행 제한 없음 | 화해 묵상·일대일 경청 |

진행 방식은 기존 실제 날짜 길이에 맞춘 당일/숙박형입니다. 참가비는 기존 금액을 1인 전체 비용으로 정한 가상 설정입니다. 실제 연락처·신청 링크·모집 확인 시각·잔여석은 만들어 넣지 않습니다. 추천 카드에는 ‘가상 시연 · 실제 모집 아님’, ‘신청 불가’를 표시합니다. 세부 구성·참가 조건은 프로그램 및 회차 상세에서 볼 수 있습니다.

## 유지한 엄격한 검사

`recommendation.js`는 이번 변경에서 수정하지 않았습니다. 공고 출처·참가 자격·선행 과정·지역·날짜·예산·동행·나이·모집 종료 검사 후 최대 3개를 선정합니다. 실제 공고로 표시한 자료에 출처가 없으면 이번 가상 조건이 있어도 추천되지 않습니다. 나이를 모르면 청년·청소년 전용 회차를 통과시키지 않습니다. 조건에 맞는 결과가 0·1·2개면 그대로 보여줍니다.

각 행은 Q1~Q10 선택지 번호(위에서부터 1번)입니다. 관심 영성·개인 조건을 추가 입력하지 않은 상태입니다.

여섯 조합은 각각 3개 결과와 서로 다른 첫 추천을 확인했습니다. 책 한 답만으로 성경이라고 단정하지 않으며 전체 답변의 실제 태그 교집합으로 순서를 정합니다.

- `tests/demo-catalog.mjs`: 6개 조합, 원본 보존, 12개/14개 메타데이터, 청년·청소년 나이, 혼자 전용, 자녀 나이, 숙박 불가, 예산, 0~3개 개수, 실제 공고 보호 검사 통과.
- `tests/recommendation-v2.mjs`: 기존 176개 확인 항목 통과.
- `tests/regression.mjs`: 14개 경로, 네 입구, 기존 묵상, 서랍 관련 렌더링, 등록·모집 상태, 0~3개 결과 HTML 검사 통과.

## 인터넷 미리보기

주소: https://gamum-v2-demo-review.knowingfjord1.chatgpt.site

Sites의 별도 소유자 전용 검토 사이트로 배포 성공을 확인했습니다. 로그인 시 현재 ChatGPT 계정으로 접속합니다. 기존 GitHub Pages·main의 변경이나 병합은 하지 않았습니다.

이 검토 사이트의 별도 소스 폴더는 작업 폴더의 `gamum-v2-preview`입니다. `.openai/hosting.json`의 연결 정보를 유지하고 같은 사이트를 갱신합니다. 정적 출력의 index.html·assets는 GitHub 작업 브랜치 파일과 바이트 단위로 대조했습니다.

초기 브라우저 설정 연결 문제가 해결된 뒤, 위 검토 사이트에 실제로 로그인하여 검사했습니다.

- 모든 문항에서 질문 위치와 스크롤 유지, 선택지 및 이동 버튼이 화면 안에 표시됨을 측정했습니다.

- 회차 상세·프로그램 상세에서 가상 구성·참가 조건·진행 방식·금액과 신청 버튼 비활성화 확인.
