## 변경

- 답변·건너뛰기 핸들러의 `window.scrollTo(0,0)` 제거. `updateQuizQuestion()`이 기존 질문 패널과 주변 화면을 보존하고 문항 내용·선택지·진행률만 변경합니다. `focus({preventScroll:true})`로 질문을 알리고, 클릭 시점의 스크롤 위치를 유지합니다. 제목 영역과 선택지의 최소 높이도 고정해 문장 길이에 따른 흔들림을 줄입니다.
- 10번째 답변이 끝난 뒤에만 결과 화면의 처음으로 이동합니다.
- 결과 순서: 유형·한 줄 설명 → 추천 3개 → 위로·성경·성인·묵상 질문·기도 → 기존 저장·공유·다시 하기 메뉴.
- 홈: 간결한 소개와 동일 위계의 네 입구, 접을 수 있는 1분 머뭄. 반복된 서랍·관리자 홍보 버튼을 정리했습니다.
- 기존 FAQ와 서랍 설명은 ‘이용 안내’로 이동했습니다. 기존 수도회 등록·관리·QR 시연은 상단 ‘수도회 전용’에서 계속 접근합니다.
- 기존 데이터와 질문·성경·성인·기도 내용, 추천 계산은 유지했습니다. 실제 피정 데이터나 새 기능은 추가하지 않았습니다.
