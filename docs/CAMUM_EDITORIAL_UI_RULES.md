# CAMUM 가뭄 — 메인 UI·UX 확정 디자인 원칙

업데이트: 2026-11-11
상태: 사용자 직접 결정 / 디자인 기준. 정식 코드 적용은 별도 검토 및 승인 필요.
적용 범위: 가뭄 신자용 메인 및 향후 디자인 시스템. 공개 main/v0.2는 변경하지 않는다.

## 브랜드
- **로고: 가뭄.** (마침표 유지)
- 한 문구만 고정하지 않는다. 메인 히어로의 짧은 **환영 문구 약 20~24개**를 사전 편집하고 **새 방문/새 세션마다 다른 문구를 보여준다**.
- 원안 **「마음이 메마른 당신에게.」는 22개 중 하나**다. 방문자가 모두 상처받은 사람인 것처럼 가정하지 않고, 쉼·성찰·기도·발견·회복·새출발을 균형 있게 표현한다.
- 한 방문 세션 안에서는 문구가 자동 회전/깜박임 없이 고정된다. 가독성 확보, 레이아웃 높이 안정화, 초기 렌더링 번쩍임 방지.
- 편집자 승인된 문구 묶음만 사용. 방문마다 AI가 즉석 생성하지 않는다. 무작위 섞기/순환(셔플백)으로 같은 문구만 연속 등장하지 않도록 한다.

## 네 가지 동등한 탐색 입구
- 상단 제목 확정 방향: **「머뭄으로 향하는 네 가지 길」**.
- 이전 「나의 머뭄을 찾는 네 가지 방법」, 「내가 머뭄을 마주하는 네 가지 방법」 대신 더 부드럽고 짧은 제목.
- 설명: 「당신에게 편안한 길에서 시작해 보세요.」
- 경로는 나를 찾아가는 길(10문항), 주제로 찾는 길, 날짜로 찾는 길, 장소로 찾는 길. 네 개 모두 동등한 발견 수단이며 실제 탐색 동작에 확실히 연결할 것.
- 아름다움 때문에 메인에서 탐색 입구가 아래로 밀려서는 안 된다. 모바일 우선.

## 빛과 건축, 영성 매거진
- 사용자가 좋아하는 롱샹 성당에서 영감을 받되 건물 형태를 베끼거나 단순히 사진만 붙이지 않는다.
- **빛·그림자·공간·침묵·여백의 관계**를 디자인한다. 고요한 종교 건축의 공간감 + 세련된 독립 영성 매거진의 편집 + 직관적인 피정 검색.
- 이미지 방향: 건축의 빛, 수도원 복도, 창, 돌담, 절제된 자연. 아이보리/돌빛/숲색/세이지, 낮은 채도와 대비. 허가받은 자료만 정식 사용.
- 제목은 절제된 명조, 긴 본문/버튼은 읽기 쉬운 고딕.
- 브랜드 정신: 머물고 싶은 공간이면서 전국 실제 피정을 쉽게 찾을 수 있는 연결 플랫폼.

## 선 굵기의 디자인 언어 — 중요 사용자 원칙
선은 장식이 아니라 화면에 공간감과 분위기를 만드는 건축 요소. **얇은 선과 굵은 선의 선택이 사이트의 인상을 바꾼다는 사실을 디자인 과정에서 잊지 않는다.**
- 가는 선 **1px**: 침묵/여백/편집의 정교함. 카드 테두리·일반 분리·보조 레이아웃. 낮고 부드러운 명암.
- 중간 선 **2px**: 질서/방향/현재 선택/진행 상태. 사용자 상호작용과 주요 제목 계층.
- 굵은 선 **5px**: 공간적 경계/리듬/강한 전환에만 제한적으로 사용. 모든 카드에 반복하지 않는다.
- 두께뿐 아니라 시작·끝 위치, 길이, 색의 명암, 주변 여백도 설계한다.
- 디바이스별 렌더링에서 너무 흐리거나 얇지 않은지 실측/스크린샷 검증한다. UI의 의미를 선 두께만으로 전달하지 않는다.

## 오늘, 1분 머뭄
- 사이트 고유 경험. 처음부터 펼쳐져 있어야 한다. 실제로 들어가 머물고 싶은 **작은 경당/빛의 방**처럼 공간 디자인.
- 위로→말씀→성찰 질문→기도 4단계; 한 번에 하나의 핵심 생각과 명확한 다음 버튼.
- 사용자의 클릭에 따라 빛의 위치·강도가 미세하게 변할 수 있으나 움직임 강요, 타이머, 자동 넘김, 소리 자동재생 금지.
- 충분한 폰트 대비, 큰 터치 영역, 키보드/스크린리더, prefers-reduced-motion 지원.
- 아름다운 분위기가 실제 피정 검색을 방해하지 않도록 시각적 강약 균형.

## 단계별 출시 제약
- **v0.21 실운영 DB·수도회 관리자 개발 브랜치는 유지**, 실제 프로그램/회차 승인 검증을 우선.
- 공개 main/v0.2를 허락 없이 바꾸지 않는다. 새 메인 디자인은 별도 리뷰 브랜치/시안에서 구현하고 실물 모바일 검증 후 공개.
- 문구 로테이션과 UI 변화가 기존 네 가지 탐색, 실제 피정 정보, 기관별 로그인, 등록·신청 경로를 손상하면 안 된다.
