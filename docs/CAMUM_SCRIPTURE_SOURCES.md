## 확인 방법

한국천주교주교회의(CBCK)의 가톨릭 새번역 **성경**(`/Knb/`) 장별 공식 페이지를 직접 열어 장절과 아래 발췌 문구를 대조했다. 공동번역이나 기억에 의존한 문장을 사용하지 않았다. 말씀 단계는 짧은 발췌이며, 생략된 절 전체와 앞뒤 문맥은 해당 공식 링크에서 읽는다. `excerpt: true`는 발췌임을 뜻한다. 시의 행갈이는 화면 폭에 맞춰 달라질 수 있으나 인용 어휘·띄어쓰기·문장부호는 유지한다. 전체 문장 바깥의 대화 따옴표와 주석 번호는 옮기지 않았다.

## 공개 전 편집 확인

- 20개 첫 문장·건축 그래픽·묵상이 같은 주제를 전달하는지 실제 PC와 모바일 화면에서 확인한다.
- 위로를 치료·결과의 보장으로 쓰지 않는다. 상처·용서는 안전, 필요한 경계, 도움 요청을 존중하며 즉각적인 화해나 관계 회복을 요구하지 않는다.
- 눈물은 슬픔의 속도를 강요하지 않고, 감사는 어려움을 억지로 긍정하라는 뜻으로 쓰지 않는다.
- 장절·발췌 문구는 검증되었으나 묵상 해석과 목회적 적절성은 최종 공개 전 편집 검수를 거친다. 각 테마의 `editorialStatus`에도 이를 표시한다.
- CBCK 성경 페이지 하단에는 인용 저작물에 대한 사용 승인 안내가 있다. 이번 디자인 검토본과 별개로, 정식 공개 전 권리자의 성경 사용 승인 요건과 처리 여부를 확인한다. 승인을 이미 받았다고 주장하지 않는다. 안내는 위 공식 원문 각 페이지 하단에서 확인할 수 있다.
- 건축 이미지는 외부 시설 사진이 아니라 이 프로젝트에서 제작한 SVG 그래픽이다. 실제 피정 시설 사진으로 소개하지 않는다.
