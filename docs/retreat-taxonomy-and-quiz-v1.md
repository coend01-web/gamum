## 0. 출발점
- 신자: 전국의 피정을 찾기 어렵고, 찾더라도 날짜·대상·연락처·신청 방법을 확인하기 어려움
- 수도회: 좋은 피정을 준비해도 홍보 채널이 적고 프로그램 관리 부담이 큼
- 10문항은 재미있는 성찰을 제공하되 실재하는 **참가 가능한** 머뭄•피정으로 연결해야 함
- 한 사람을 8개 고정 유형에 가두지 말고 **복수 태그와 명시적 제약**을 조합해 추천
- 결과 상단 = 짧은 유형·위로 한 줄 → 실제 추천 프로그램 (가능한 경우 3개) → 위로·성경·성인·묵상·기도
- 실제 등록된 프로그램이 3개 미만이면 없는 추천을 채우거나 가짜 프로그램을 제시하지 않음

## 2. 분류체계: '한 가지 피정 종류'가 아니라 다차원
프로그램은 복수 태그를 가질 수 있음. 운영 기관 등록 때 아래 각 축에 적절한 값을 부여하고, 명부에 없는 형식은 검증 후 추가 가능.

A. **목적/삶의 주제**:
`rest` 쉼/재충전, `faith-renewal` 신앙 재시작, `scripture` 말씀, `discernment` 식별/인생 선택, `vocation` 성소 탐색, `relationship` 가족/부부/관계, `reconciliation` 화해·용서, `spiritual-healing` 영적 위로·치유, `gratitude` 감사, `formation` 신앙교육, `community` 공동체, `ecology` 생태영성, `mission` 선교·봉사, `liturgical-season` 대림·사순·성삼일 등

B. **영성·기도 전통**:
`ignatian` 이냐시오 영신수련, `lectio` 렉시오 디비나/성경 묵상, `contemplative` 관상·향심기도, `jesus-heart` 예수마음기도, `eucharistic` 성체조배·미사 중심, `charismatic` 성령쇄신·찬양, `marian` 성모신심, `benedictine` 베네딕도 영성, `carmelite` 가르멜 영성, `franciscan` 프란치스코 영성, `monastic` 수도생활, `pilgrimage-retreat` **신청·진행이 피정 성격으로 검증된 순례형 피정만** (단순 여행 광고 제외)

C. **운영방식**:
`silent` 대침묵, `partial-silence` 부분 침묵, `self-directed` 자유/개인, `guided` 지도형, `one-on-one` 개별 면담, `lecture` 강의, `sharing` 나눔, `communal-prayer` 공동기도, `praise` 찬양, `walking` 걷기, `arts` 음악·미술·영상·창작, `service` 체험·봉사, `residential` 숙박, `daytime` 당일, `commuter` 출퇴근/생활 속, `online` 온라인, `group-exclusive` 단체 위탁

D. **대상·자격(배타적 필터, 점수로 무시하면 안 됨)**:
연령 범위, 청소년/청년/중년/시니어, 성인 전체, 부부/가족/모녀 등 특정 동반 조건, 개인/본당단체 신청, 성소 관심자, 남녀 제한(주최 측 명시 때만), 성직자·수도자 전용, 세례·성사 여부/경험·선행과정, 난이도·침묵 경험, 접근성·숙박 형태

E. **회차 실무**:
실제 시작·종료 날짜, 신청 시작·마감, 참가비·추가비·개인당/팀당 단위, 위치, 숙박/통원, 잔여 좌석 확인 여부, 모집 상태와 확인 시각, 공식 연락처와 신청 URL

## 3. 완성형 10문항 v1.0 (4~6개 선택지, 매 문항 한 개 선택, '건너뛰기' 허용)

## 4. 추천 로직: 감성 점수와 신청 가능 조건은 서로 다르게 처리
1) **후보 수집:** 현재 또는 미래 회차가 있고 신뢰할 수 있는 공식 안내가 연결된 프로그램만.
2) **필수 적합성 필터:** 공개 대상(연령·자격·인원·성별 제한 등), 일정·장소·예산 등 사용자가 명시한 조건과 모순되지 않아야 함. 연령 등 미확인 조건은 '참가 대상 확인 필요'로 표시하고 확정 추천·예약 가능으로 단정 금지.
3) **선호 점수:** Q1~4의 주제·영성 선호, Q5~7 진행 방식, Q8 초심/심화 안내, Q9 시간 적합, Q10 동행 적합을 다차원 가중치로 계산. Q1 2점, Q2 3점, Q3 3점, Q4 3점, Q5 3점, Q6 2점, Q7 3점, Q8 경험 수준 2점, Q9 시간 4점, Q10 동행 4점은 **초기 임시 가중치**일 뿐이며 실사용 평가로 조정.
4) **소프트 반대조건:** Q7에서 나눔을 원하면 장기 완전 침묵 피정의 순위를 낮춤. 영신수련·대침묵 등을 무조건 배제하지는 않음. 단 대상·선행 필수 조건을 어기지 않음.
5) **다양성:** 최대 3개 추천이 모두 동일 유형이라면 충분히 적합한 후보 안에서 방식·수도회·지역 다양화. 유명 수도회만 노출하지 말 것.
6) **설명:** '당신이 ○○을 원했고, 이 피정에 ○○ 과정이 있어 추천합니다'처럼 실제 공고 태그에 근거한 1문장. 없는 기도·일정을 만들어내지 말 것.
7) **현재 모집 가능 확인:** 연동이 확실하고 상태가 갱신된 경우에만 모집 중으로 표시. 그렇지 않으면 '주최 측 확인 필요', 공식 문의·신청 링크는 반드시 표시.
8) **모집 후보 부족 시:** 3개 숫자를 억지로 채우지 말고 '관련 피정 더 보기', 날짜/지역 넓히기, 수도회 공식 사이트 보기로 연결.
9) **민감한 응답:** 슬픔·관계 문제를 병명이나 위험 수준으로 진단하지 않고 세밀한 감정 답변을 기본적으로 계정에 저장하지 말 것.

## 5. 결과 화면 순서 (기존 합의 유지)
1. '지금 당신에게 어울리는 머뭄' 제목 + 짧은 격려, 10문항 완료
2. **실제 추천 머뭄•피정** (가능하면 3개; 사진, 기관, 날짜, 지역, 비용, 대상, 모집 확인 시각, 공식 신청 링크)
3. '추천 조건 조정' : **지역 / 날짜 / 예산 / 참가자 연령·대상 / 숙박 가능 여부**; 결과 자체를 초기화하지 않고 재탐색
4. **작은 피정**: 위로의 말 → 가톨릭 새번역 성경의 공식 장절 링크 → 검증된 영적 길동무 성인 → 묵상 질문 → 짧은 기도
5. 결과 저장·공유 / 다시 검사
항상 '가상 시연'과 실제 검증된 데이터를 명확하게 구별. 사용자가 10번째 답변을 클릭하면 위로가 아니라 **실제 추천 시작 부분**으로 접근 가능하게.
복잡한 화면으로 돌아가지 않도록 기존 홈의 네 가지 입구는 보존.

## 6. 수도회 등록 필수 정보
프로그램 (고정): 제목, 수도회/피정의 집, 주제 다중 태그, 방식/침묵 수준, 대상/자격, 일정 형태, 프로그램 내용, 허용된 사진, 연락처·공식 신청 페이지
회차 (유동): 시작·끝, 참가비, 정원, 신청시작·마감, 선착순/승인제, 잔여석 확인 근거, 모집 상태, 예외/조기마감
가뭄은 기존 수도회 직접 결제·환불 방식을 유지하고, 수도회 수수료는 부과하지 않음.

## 7. 필수 검증 사례
- 쉼+당일+혼자 → 실제 당일 개인/일반 피정을 우선, 장기 30일 피정을 앞세우지 않음
- 식별+영신수련+심화+장기 → 영신수련 후보, 선행경험은 주최 측 확인
- 성경+독서+강의 → 렉시오 디비나·성경통독·성서연수 후보
- 찬양+공동기도+나눔 → 성령/찬양 형태가 있는 공고만 가산
- 침묵이 어렵다+나눔 선호 → 장기 대침묵 과도 추천 방지
- 배우자 동행 → 혼인·부부 대상 프로그램 우선, 단체/개인 허용 조건도 확인
- 가족 동행 → 가족·부모자녀 대상과 숙박 가능 여부 확인
- 미성년 대상 → 연령 확인 없는 성인 전용 프로그램 추천 금지
- 출퇴근·온라인만 가능 → 숙박형 피정만 3개 제시하는 오류 금지
- 예약 마감·모집 불명 → 실시간 신청 가능으로 표기하지 않음
- 부족한 후보 0~2개 → 가상 데이터로 채우지 않고 조건 조절 안내
- 청소년 캠프, 수도자 대상 위탁피정, 재직 봉사자 전용 프로그램은 누구에게나 열려 있는 일반 피정으로 혼동하지 않음

## 8. 구현 체크리스트
- 질문 답변 때 화면이 위로 튀지 않음, 키보드·모바일 접근성 유지
- 각 답변/태그/가중치를 JS 한 곳(또는 JSON)에서 관리 가능
- 진단·고정된 성격 판정 표현 금지
- 10문항 완료 후 앞부분에 추천, 다음에 성경·성인·묵상
- 현재 가뭄 검색·일정·장소·수도회 화면/서랍/1분 머뭄 기능 모두 회귀 테스트
- **작업은 별도 브랜치에서**, main 공개 홈페이지는 최종 승인 전까지 수정하지 않음
- 테스트용 데이터의 '가상' 표시 및 실제 승인된 정보와의 혼동 방지
